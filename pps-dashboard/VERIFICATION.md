# Vercel + Supabase 전환 검증

2026-10-19 기준, Node 24에서 검증했습니다.

- `npm run build`: TypeScript 검사 및 Vite 프로덕션 빌드 통과
- `npm test`: 9개 테스트 통과
- Supabase 모의 응답: 원자 저장 성공, 오래된 버전 저장 409 거부, 새 요청의 영속 상태 조회
- 관리자 로그인/로그아웃, HttpOnly 세션, 비인증 API/파일 차단, 다른 출처의 쓰기 차단
- 기간·누적 계산, 미래 수치 제외, 미확인과 0% 구분, 동일 집합 비교
- 반복 보고/활동 수집 중복 방지, 확정 연결/보정 기간 보존, 원문 변경 검토
- 분할 노션 수집: 스키마 끝 공백, 페이지/하위 블록 커서, 중첩 블록, 429 재시도
- 가상 PDF 테스트: Python 없이 Node에서 읽기, 알 수 없는 양식의 업무를 만들지 않음
- 기존 실제 PDF는 로컬에서만 읽어 12페이지·90개 후보 행을 확인했습니다. 원본은 Git에 포함하지 않습니다.

Supabase 실제 프로젝트 마이그레이션 적용, Vercel 배포/라우팅 실증, 실제 토큰을 사용한 Notion 전체 동기화는 아직 수행하지 않았습니다. 브라우저 시각 E2E도 미수행입니다. 테스트에 사용하는 Supabase/Notion은 가상 응답이며 운영 연결 완료를 의미하지 않습니다.

실제 업무 데이터는 저장소 밖에서 보관하고 `scripts/import-private-data.ts`로 비공개 Supabase에 이관합니다. 공개 저장소/프런트엔드 번들에 회사 원문이나 서버 비밀 키를 넣지 않습니다.
